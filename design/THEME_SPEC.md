两套主题共享同一套组件和布局。主题切换只改变色彩、边框、阴影与对应 logo，不改变文字、数据、表格位置或当前操作状态。

## 图标与组件

- 应用 logo 固定为用户选定的立体立方体；深浅模式均不改成盾牌、十字或平面方块。
- 实现时准备同形状的透明底蓝白、石墨薄荷绿两份 logo 素材。去除图标外围底色时保留中央立方体的浅色内芯。
- 顶部 logo 约 36–40px，与“训练工作台”标题对齐；导航及操作图标采用统一线宽的组件图标。
- 常规卡片圆角约 8–10px，间距遵循 8px 网格；表格数字使用等宽数字。中文优先 Microsoft YaHei UI/系统无衬线字体，日志优先 Cascadia Code/Consolas。
- 深色采用细边框和层次清晰的表面色；浅色采用很轻的冷色阴影。保持克制，不增加山景、装饰插画或发光背景。
- 表格和检查器提供清晰焦点态、错误态与禁用态；日志和长路径可横向滚动或展开，不挤压关键数值。

## 主题切换

- 右上角固定太阳/月亮分段切换控件，显示“浅色”“深色”及明确选中态。
- 使用根节点 `data-theme` 和语义 CSS 变量；logo 随同一主题状态切换。
- 首次默认深色；使用 localStorage 键 `isaaclab-workbench.theme` 保存 `dark` 或 `light`，无效值回退深色。
- 首屏绘制前应用已保存主题，避免浅色闪烁；切换不触发页面刷新或训练服务重启。
- 所有页面、弹窗、日志区和表单使用相同 token；主题是浏览器外观偏好，不写入实验配置。
